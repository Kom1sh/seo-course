# Дека «Поиск и ИИ-выдача», встреча 1 — дизайн

**Дата:** 2026-09-07. **Заказчик:** Егор (спикер). **Аудитория:** бакалавры 1–3 курсов Школы Икс, факультатив в субботу, 90 минут.

## Цель
Первая из пяти встреч по продвижению веб-проектов в поисковиках и ИИ-выдаче. Задача встречи — дать карту местности
(как работает поиск, что видит пользователь, как отвечает ИИ) на двух живых проектах спикера и оставить задел на серию.
Не учебник по всему SEO: техничка, семантика, ссылки и GEO-практикум — отдельные встречи.

## Решения, принятые без Егора (он не на связи)
1. Стиль — DESIGN.md проекта, донор токенов Miro из каталога awesome-design-md: белый холст, маркер-жёлтый, стикеры. Отличается от кремово-оранжевой деки ПАС намеренно.
2. Шрифты — Unbounded (заголовки), Golos Text (текст), JetBrains Mono (запросы/URL); вшиты base64, только latin+cyrillic.
3. Данные — Метрика, Вебмастер, Search Console по API напрямую (MCP в сессии не поднялись), снимок в `src/data.json`, чтобы сборка не требовала секретов.
4. Иллюстрации — скриншоты сайтов в browser-frame, графики SVG из данных, макет выдачи на HTML, логотипы Simple Icons, схемы на CSS.
5. Серия из пяти встреч — рабочее название и порядок предложены в деке, правится в `src/content.py`.
6. Репозиторий публичный (Pages без Pro иначе не работает), закрыт от индексации: `<meta name=robots noindex,nofollow,noarchive>`, `robots.txt` Disallow, `X-Robots-Tag` на Pages недоступен.

## Структура (пять разделов, ~40 слайдов)
0 Обложка, спикер, зачем, два графика-крюка, план серии, план встречи ·
1 Как работает поиск: термины, рынок, три шага, сканирование, индексация, ранжирование, намерение запроса ·
2 Что видит пользователь: анатомия выдачи, сниппет, позиция и CTR, zero-click ·
3 ИИ-выдача и GEO: где ищут, как отвечает ИИ, четыре индекса, что влияет на цитирование, SEO против GEO ·
4 Два кейса: мапка.рф (индекс 36→454, показы ×10), techkio.ru (0→4 908 визитов за 8 недель), общий урок ·
5 Практикум: проверь проект за 10 минут, инструменты, домашка, анонс встречи 2, источники, контакты.

## Техника
Движок деки ПАС (сцена 1600×900, absolute-центрирование, стрелки/O/F, печать в PDF, QA-хук `?qa=1`).
`src/content.py` → `src/make_slides.py` → `src/slides.html` → `src/build.py` → `index.html`. `src/qa.py` обязателен перед отдачей.

## Проверка
`python3 src/qa.py` без дефектов; контактный лист глазами; PDF-экспорт; страница отдаёт noindex; Pages отвечает 200.
