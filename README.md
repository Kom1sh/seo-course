# Поиск и ИИ-выдача — встреча 1

HTML-презентация факультатива по продвижению веб-проектов для Школы Икс.
41 слайд, формат 16:9, открывается в браузере без интернета.

**Живая версия:** https://kom1sh.github.io/seo-course/ — закрыта от индексации
(`noindex` в мета-теге и `Disallow: /` в robots.txt).

## Управление

Стрелки или пробел — слайды, `O` — сетка всех слайдов, `F` — полный экран,
`#12` в адресе открывает слайд 12. Работает с телефона свайпом.

## Что внутри

Пять разделов: как работает поиск, что видит пользователь в выдаче, ИИ-выдача
и GEO, два кейса с цифрами (мапка.рф и techkio.ru), практикум и домашнее задание.
Все числа — из Яндекс Метрики, Яндекс Вебмастера и Google Search Console
на 6 сентября 2026, снимок лежит в `src/data.json`.

## Как править

`index.html` — собранный артефакт, руками не трогать: 240 КБ из 455 это шрифты в base64.

```
python3 src/make_slides.py   # содержание и разметка слайдов → src/slides.html
python3 src/build.py         # склейка с шаблоном → index.html
python3 src/qa.py            # обязательная проверка вёрстки перед отдачей
```

- `src/make_slides.py` — все тексты, данные и генераторы графиков.
- `src/deck.tpl.html` — оформление и логика показа.
- `DESIGN.md` — дизайн-контракт: палитра, шрифты, компоненты, запреты.
- `src/data.json` — снимок данных; обновляется скриптами из `tools/`.
- `src/fetch_fonts.py`, `src/fetch_icons.py` — шрифты и спрайт логотипов.

`src/qa.py` поднимает локальный сервер, прогоняет все слайды и ловит обрезанный
текст, вылет за кадр, элементы вне карточек и наложения. Кладёт контактный лист
в `deck-qa/sheet.png`. Возвращает код 1 при дефектах — деку с дефектами не отдаём.

## Обновить данные

Нужны токены: `~/.claude/secrets/yandex-webmaster-token`,
`~/.claude/secrets/yandex-metrika-token`, `~/.claude/secrets/gsc-service-account.json`.

```
SEO_DUMP=/tmp/seo python3 tools/pull_webmaster_gsc.py
SEO_DUMP=/tmp/seo python3 tools/pull_metrika.py
SEO_DUMP=/tmp/seo python3 src/snapshot_data.py
```
