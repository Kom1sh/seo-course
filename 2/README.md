# Семантика и структура сайта — встреча 2

Живая версия: https://kom1sh.github.io/seo-course/2/ — закрыта от индексации, как и первая встреча.
41 слайд на 90 минут. Управление то же: стрелки, `O` — обзор с миниатюрами, `F` — полный экран.

## Что внутри

Ход работы по порядку: заходим в Вордстат, собираем и чистим запросы, раскладываем их по кластерам, под кластеры делаем посадочные и статьи блога, связываем страницы ссылками и проверяем, что сирот нет. Платные сервисы собраны на одном слайде «Что ещё бывает» — для учебного проекта хватает Вордстата.

Слайды, убранные из показа (подсказки, свой Вебмастер, андезит, фасеты, адреса, глубина и др.), остались в `src/make_slides.py`; что показывать и в каком порядке, задаёт список `ORDER` в конце файла.
На слайде про проверку структуры — QR-код на бесплатное расширение SiteAnalyzer SEO Tools в магазине Chrome.
Сквозной учебный кейс — ниша, которую выбирает зал на пятом слайде; ход показан на школе английского.

Все цифры — Яндекс Вебмастер, Google Search Console и Яндекс Метрика по мапка.рф и techkio.ru
за 13 августа — 12 сентября 2026, подсказки Яндекса и карты сайтов сняты 14 сентября 2026.
Снимок лежит в `src/data.json`.

## Как править

```
python3 src/make_slides.py && python3 src/build.py && python3 src/qa.py
```

Обновить данные: выгрузки из `../tools/` в каталог `$SEO_DUMP`, подсказки и sitemap Мапки туда же,
затем `SEO_DUMP=<каталог> python3 src/snapshot_data.py`.
